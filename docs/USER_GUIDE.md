# 사용자 가이드

## 시작하기

### 첫 방문

1. 웹사이트에 접속하세요
2. 검색창에 원하는 개발 리소스를 입력하세요
   - 예: "이미지 분석 봇 만들고 싶어"
   - 예: "Python AI 라이브러리"
   - 예: "React 컴포넌트"

### 검색 기능

#### 자연어 검색

일반적인 문장으로 검색하면 AI가 의도를 파악하여 관련 리소스를 찾아줍니다.

- "웹 크롤러 만들고 싶어" → 크롤링 관련 라이브러리 추천
- "데이터베이스 연결" → DB 관련 도구 추천
- "UI 디자인 도구" → 디자인 리소스 추천

#### 카테고리 필터

검색 결과를 카테고리별로 필터링할 수 있습니다:

- **SKILLS**: 에이전트 스킬, CLI 확장도구
- **TOOLS**: 라이브러리, API
- **EXTENSION**: VS Code 확장도구

#### 리소스 타입 필터

- CLI_EXTENSION: CLI 확장도구
- AGENT_SKILL: AI 에이전트 스킬
- LIBRARY: 라이브러리
- VSCODE_EXT: VS Code 확장도구
- API: API 서비스
- STARTER_KIT: 스타터 키트

## 주요 기능

### 1. 통합 리소스 검색

GitHub 라이브러리, API, CLI 확장도구, 에이전트 스킬, 스타터 키트를 한 번에 검색할 수 있습니다.

### 2. 소셜 트렌드 오토 리서치

X (Twitter), Threads에서 #aiagent, #vibecoding 해시태그를 모니터링하여 최신 트렌드 리소스를 자동으로 수집합니다.

### 3. 링크 헬스 가드

등록된 리소스의 URL 유효성을 실시간으로 확인하고, Broken Link를 자동으로 감지합니다.

### 4. 사용자 주도 학습

GitHub 또는 문서 URL을 입력하면 AI가 내용을 분석하여 즉시 리소스로 등록합니다.

## 리소스 카드 정보

각 리소스 카드에는 다음 정보가 표시됩니다:

- **제목**: 리소스 이름
- **타입**: 리소스 유형 (라이브러리, API 등)
- **설명**: 리소스에 대한 간단한 설명
- **플랫폼**: 지원하는 플랫폼 (Python, JavaScript 등)
- **태그**: 관련 태그
- **소스**: 리소스 출처 (GitHub, 공식 사이트 등)
- **상태**: 링크 상태 (활성, 비활성 등)
- **스타**: GitHub 스타 수 (있는 경우)
- **소셜 메트릭**: 좋아요, 공유 수 (있는 경우)
- **명령어**: 설치/사용 명령어 (있는 경우)

## 다크모드

헤더 우측의 다크모드 토글 버튼을 클릭하여 다크모드를 활성화/비활성화할 수 있습니다. 설정은 자동으로 저장됩니다.

## 팁

### 효과적인 검색

1. **구체적으로 검색**: "Python 라이브러리"보다 "이미지 처리 Python 라이브러리"가 더 좋습니다
2. **자연어 사용**: 질문 형식으로 검색하면 더 나은 결과를 얻을 수 있습니다
3. **필터 활용**: 카테고리와 타입 필터를 조합하여 원하는 리소스를 빠르게 찾으세요

### 리소스 추가

새로운 리소스를 발견했다면 URL 입력 폼을 통해 추가할 수 있습니다. AI가 자동으로 분석하여 등록합니다.

## 문제 해결

### 검색 결과가 없을 때

- 검색어를 더 구체적으로 입력해보세요
- 필터를 제거하고 다시 시도해보세요
- 다른 키워드로 검색해보세요

### 링크가 작동하지 않을 때

- 링크 상태 표시를 확인하세요 (빨간색 = 비활성)
- 일정 시간 후 자동으로 재확인됩니다
- 문제가 지속되면 다른 리소스를 사용해보세요
